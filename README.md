# Latus Autos

A car dealership landing page built as part of **The Odin Project Foundations course**.

## About the Project

Latus Autos is a fictional car dealership website created to practice the HTML and CSS skills I have learned through The Odin Project.

I designed the page around a car dealership theme and focused on creating a structured layout with different sections for the dealership's content.

## Built With

* HTML5
* CSS3
* Flexbox

## What I Learned

While building this project, I practiced and improved my understanding of:

### HTML

* Structuring a webpage using HTML elements.
* Using headings (`h1`–`h6`) to organize content.
* Understanding the difference between `div`, `section`, and other semantic elements.
* Grouping related content into containers.
* Creating links and working with images.
* Organizing a webpage into sections such as a header, main content, and footer.

### CSS

* Using CSS selectors to target elements.
* Styling elements through classes and element selectors.
* Working with colors, fonts, backgrounds, spacing, margins, and padding.
* Controlling the width of content using properties such as `width` and `max-width`.
* Understanding how text wraps inside a container.
* Using positioning such as `static`, `relative`, `absolute`, `fixed`, and `sticky`.
* Understanding how different CSS properties affect the layout of a webpage.

### Flexbox

This project also gave me more practice with Flexbox, including:

* Understanding the difference between a flex container and flex items.
* Using `display: flex`.
* Understanding the default `flex-direction: row`.
* Changing the direction with `flex-direction`.
* Using `gap` to create space between flex items.
* Understanding `flex-grow`.
* Understanding `flex-shrink`.
* Understanding `flex-basis`.
* Understanding the `flex` shorthand property.
* Using Flexbox to arrange and distribute content.

## What I Practiced

One of the main things I wanted to understand through this project was not just how to make a webpage look good, but **why different HTML and CSS properties produce different results**.

I practiced building the page section by section and using Flexbox to control the relationship between parent containers and their child elements.

## Future Improvements

As I continue learning through The Odin Project, I plan to improve this project by applying new concepts such as responsive design, more advanced CSS techniques, and JavaScript functionality.
